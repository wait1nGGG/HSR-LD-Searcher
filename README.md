# HSR-LD-Searcher

「崩坏：星穹铁道」牢大搜索站，支持搜索与下载。

## 功能

- **图片搜索** — 按标签搜索牢大图，支持灯箱预览与下载
- **音乐搜索** — 按歌名搜索，支持 1x / 2x 版本下载

## 访问

通过Github Pages网址访问：
```
https://<你的用户名>.github.io/HSR-LD-Searcher/
```
